本题是 **USTB-SCC 校内赛 C 题**，是一道 CUDA kernel 优化题。提交编辑器中会提供一份朴素 CUDA 初始代码，该代码能够正确完成计算，但没有进行高性能优化。你的目标是在保持正确性的前提下优化 `run_kernel` 的运行时间，也可以完全重写实现，但接口必须保持不变。

你需要优化的不规则分组混合精度矩阵乘算子为：

```text
D[i, :] = dequant_fp8(A[i, :], A_scale[i, :]) @ dequant_int4(B[m_indices[i]], B_scale[m_indices[i]]).T
```

其中 `m_indices[i]` 表示第 `i` 行 token 使用哪个 group 的权重矩阵。若 `m_indices[i] == -1`，该行是 padding 行，输出必须为 0。

本题中 activation `A` 使用 FP8 E4M3 存储，并配有 per-token、按 K 维 128 分块的 scale。权重 `B` 使用 signed INT4 packed 存储，每个字节包含两个 INT4 值，并配有按 group、输出行、K 维分块的 scale。

评测程序会调用你提交代码中的 `run_kernel` 函数。你需要在函数内部完成 FP8 反量化、INT4 unpack/反量化、不规则 grouped GEMM 和 padding 行处理。

初始代码采用一个线程计算一个输出元素的朴素实现，主要用于说明接口和计算语义。该实现会反复读取 scale、逐元素 unpack INT4，并且没有利用同 group 权重复用、矩阵分块或 Tensor Core。比赛成绩将主要取决于你对这些过程的优化效果。

提交代码必须先通过正确性检查；只有正确通过后，运行时间才会计入成绩。

本题目标平台为 **NVIDIA A800**（Ampere 架构，SM 8.0），参赛提交仅允许使用 CUDA 实现。
