---
sectionTitle: "输入格式"
type: "Text"
---

评测程序会在 GPU 上构造以下输入，并按顺序传入 `run_kernel`：

| 序号 | 参数名 | dtype | shape | 读写属性 | 说明 |
|:---:|--------|-------|-------|:-------:|------|
| 1 | `Q` | bf16 | `[B, H, S, D]` | INPUT | Query 矩阵，连续存储，值范围 $[-1, 1]$ |
| 2 | `K` | bf16 | `[B, H, S, D]` | INPUT | Key 矩阵，连续存储，值范围 $[-1, 1]$ |
| 3 | `V` | bf16 | `[B, H, S, D]` | INPUT | Value 矩阵，连续存储，值范围 $[-1, 1]$ |
| 4 | `mask` | bf16 | `[B, 1, S, S]` | INPUT | causal mask 或 `nullptr`。上三角为 `-inf`（bf16），下三角为 `0`。当为 `nullptr` 时表示无 mask |
| 5 | `B` | int64 | 标量 | INPUT | batch size |
| 6 | `H` | int64 | 标量 | INPUT | head 数量 |
| 7 | `S` | int64 | 标量 | INPUT | 序列长度 |
| 8 | `D` | int64 | 标量 | INPUT | head 维度 |
| 9 | `alpha` | float32 | 标量 | INPUT | scale 因子，$\alpha = 1 / \sqrt{D}$ |
| 10 | `O` | bf16 | `[B, H, S, D]` | OUTPUT | 输出矩阵，连续存储，kernel 写入前内容未定义 |

**补充说明**：

- 所有 tensor 在 GPU 上连续分配（row-major 布局），stride 为标准值
- `Q`、`K`、`V` 的数值由均匀分布 $\mathcal{U}(-1, 1)$ 随机生成，确保 softmax 不会因极端值溢出
- `mask` 的 `-inf` 值以 bf16 的负无穷表示，即 `0xFF80`（符号位=1，指数全 1，尾数全 0）
- 当 `mask` 为 `nullptr` 时，等价于全零 mask
