提交编辑器中的初始代码已经提供如下 **C 符号**。你可以修改内部实现，也可以重写辅助 kernel，但必须保留该入口函数。函数名、参数类型、参数顺序必须完全一致，并使用 `extern "C"` 防止 name mangling：

```cpp
#include <stdint.h>
#include <cuda_bf16.h>
#include <cuda_fp8.h>

extern "C" void run_kernel(
    const __nv_fp8_e4m3* A,
    const float* A_scale,
    const uint8_t* B_packed,
    const float* B_scale,
    const int32_t* m_indices,
    __nv_bfloat16* D,
    int64_t M_total,
    int64_t K,
    int64_t N,
    int64_t num_groups,
    int64_t group_k
);
```

### 参数说明

* `A`：FP8E4M3 输入矩阵，shape `(M_total, K)`，只读
* `A_scale`：float32 scale，shape `(M_total, ceil(K/128))`
* `B_packed`：signed INT4 packed 权重，shape `(num_groups, N, ceil(K/2))`
* `B_scale`：float32 scale，shape `(num_groups, N, ceil(K/group_k))`
* `m_indices`：int32 分组索引，shape `(M_total,)`，取值为 `-1` 或 `[0, num_groups)`
* `D`：BF16 输出矩阵，shape `(M_total, N)`
* `M_total`、`K`、`N`、`num_groups`：对应维度
* `group_k`：B 的 INT4 scale 在 K 维的分块大小，demo 中固定为 64

### 优化目标

`run_kernel` 内部不应依赖 CPU 计算，不应在计时路径中主动同步。允许定义额外的 `__global__` kernel、device helper、模板和常量，但对外暴露的入口必须是上面的 `run_kernel`。
