你必须在提交的 Python 代码中提供 `run_kernel` 函数，函数名、参数顺序、类型必须完全一致：

```python
def run_kernel(
    expert_tokens,          # Tensor[float16], shape (group_sum, d_hidden)
    routed_expert_gate,     # Tensor[float16], shape (n_routed_experts, d_expert, d_hidden)
    routed_expert_up,       # Tensor[float16], shape (n_routed_experts, d_expert, d_hidden)
    routed_expert_down,     # Tensor[float16], shape (n_routed_experts, d_hidden, d_expert)
    routed_expert_weights,  # Tensor[float16], shape (group_sum,)
    group_sizes,            # Tensor[int32], shape (n_routed_experts,)
    group_offsets,          # Tensor[int32], shape (n_routed_experts,)
    group_padded_offsets,   # Tensor[int32], shape (n_routed_experts,)
    group_idx_for_bx,       # Tensor[int32], shape (ceil(group_sum / 128) + n_routed_experts,)
    up_logits,              # Tensor[float16], shape (group_sum, d_expert), workspace
    output,                 # Tensor[float16], shape (group_sum, d_hidden)
    group_sum,              # int64
    d_hidden,               # int64
    d_expert,               # int64
    n_routed_experts,       # int64
    block_token,            # int64, fixed to 128 in tests
):
    ...
```

### 参数说明

* `expert_tokens`：已按 expert 分组后的 token，shape `(group_sum, d_hidden)`
* `routed_expert_gate`：gate projection 权重，shape `(n_routed_experts, d_expert, d_hidden)`
* `routed_expert_up`：up projection 权重，shape `(n_routed_experts, d_expert, d_hidden)`
* `routed_expert_down`：down projection 权重，shape `(n_routed_experts, d_hidden, d_expert)`
* `routed_expert_weights`：每个 routed token 对应的 top-k 路由权重，shape `(group_sum,)`
* `group_sizes[e]`：第 `e` 个 expert 的 token 数
* `group_offsets[e]`：第 `e` 个 expert 在连续 token 缓冲区中的起始偏移
* `group_padded_offsets`、`group_idx_for_bx`：按 `block_token` 分块后的辅助 metadata，可用于 TileLang grouped GEMM 调度
* `up_logits`：中间 workspace，可写入 `silu(gate) * up`
* `output`：输出缓冲区，必须写入最终结果

`run_kernel` 内部应自行缓存/编译 TileLang kernel，并完成 fused gate/up/down 计算。
