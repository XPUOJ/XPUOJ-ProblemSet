你需要实现 DeepSeek 风格 MoE 中的 pre-routed fused expert GEMM。

本题已经完成 routing、token 分组和 group metadata 构造。给定按 expert 连续排列的 token、每个 expert 的 gate/up/down 权重、每个 routed token 的路由权重，你需要计算：

```text
hidden = silu(expert_tokens @ W_gate[e]^T) * (expert_tokens @ W_up[e]^T)
output = hidden @ W_down[e]^T * routed_expert_weights
```

其中 `e` 由 `group_sizes` 和 `group_offsets` 决定。相同 expert 的 token 在 `expert_tokens` 中连续存放。

评测程序会调用你提交代码中的 `run_kernel` 函数。你需要在函数内部调用 TileLang kernel 或等价的 GPU tensor 算子完成上述计算。

如何提交代码详见[评测指南](/d/2)。
