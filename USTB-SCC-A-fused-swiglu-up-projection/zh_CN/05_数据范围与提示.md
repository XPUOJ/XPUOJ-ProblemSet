数据范围与约束：

| 项目 | 约束 |
| --- | --- |
| `x`、`w_gate`、`w_up`、`y` | `bf16` |
| `b_gate`、`b_up` | `fp32` |
| tensor 存储 | 全部 contiguous，row-major |
| 可修改参数 | 只能写 `y`，不允许修改其他输入 tensor |
| 输出要求 | `y` 必须完整覆盖，不能依赖初值 |
| `M` | `1024 <= M <= 8192` |
| `K` | `1024 <= K <= 6144` |
| `N` | `2048 <= N <= 6144` |
| 边界要求 | `M`、`K`、`N` 不保证是 block size 或 tile size 的倍数 |
| 正确性容差 | `rtol = 5e-2`，`atol = 5e-2` |

正式测试点全部隐藏。评测会覆盖中等规模、大 `M`、大 `K`、大 `N`、近似方阵，以及 `M/K/N` 不能被常见 tile size 整除的边界场景。参赛者应基于算子结构和形状特征进行通用优化，不应依赖固定测试点写死实现。

优化提示：

可以把本题看作两个共享 `x` 的 GEMM 加一个融合 epilogue。常见 Triton 优化方向包括调优 `BLOCK_M/BLOCK_N/BLOCK_K`、复用 `x` 的 tile 加载、同时计算 gate/up 两个分支、把 bias、SiLU 和逐元素乘融合到输出阶段、避免把两个中间矩阵完整写回全局内存。非整除测试点需要正确处理边界 mask。

性能统计口径中，FLOPs 约为 `4 * M * K * N + 8 * M * N`，主访存按读取 `x`、两份权重、两份偏置并写出 `y` 的外部 tensor 流量估算。
