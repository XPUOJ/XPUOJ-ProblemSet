本题是 **USTB-SCC 校内赛 A 题**，是一道 Triton kernel 优化题。提交编辑器中会提供一份朴素 Triton 初始代码，该代码能够正确完成计算，但没有进行高性能优化。你的目标是在保持正确性的前提下优化 `run_kernel` 的运行时间，也可以完全重写实现，但接口必须保持不变。

本题要求优化一个融合的 SwiGLU 上投影算子。给定输入矩阵 `x`、两组权重 `w_gate` 与 `w_up`，以及两组偏置 `b_gate` 与 `b_up`，需要计算：

```text
gate = x @ w_gate + b_gate
up   = x @ w_up   + b_up
y    = silu(gate) * up
```

其中 `silu(t) = t / (1 + exp(-t))`。`x`、`w_gate`、`w_up` 和 `y` 使用 `bf16`，两个偏置使用 `fp32`。矩阵乘部分按概念上的 `fp32` 累加定义，最终结果写回 `bf16` 输出矩阵 `y`。

初始代码采用显式 K 维循环的朴素 Triton 实现，主要用于说明接口和计算语义，并没有使用 `tl.dot`/Tensor Core 或高性能矩阵分块。相比普通矩阵乘，本题多了两路共享输入的矩阵乘、偏置、非线性激活和逐元素门控乘法。参赛者可以选择先分别完成两次 GEMM，也可以在 tile 级别复用 `x` 的加载、融合 epilogue、减少中间结果写回，优化空间较大。

评测程序会在 GPU 上构造输入，并调用参赛者提交代码中的 `run_kernel` 函数。`run_kernel` 不需要返回值，但必须完整写入输出 tensor `y`。

本题目标平台为 **NVIDIA A800**（Ampere 架构，SM 8.0），参赛提交仅允许使用 Triton 实现。

如何提交代码详见[评测指南](/d/2)。
