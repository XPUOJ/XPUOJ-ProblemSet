下面给出一个概念样例，真实评测数据由 `testcase_config.py` 生成。

设 `M = 1`、`K = 2`、`N = 2`：

```text
x = [[1, 2]]

w_gate = [[1, 0],
          [0, 1]]

w_up = [[2, 1],
        [1, 3]]

b_gate = [0, 0]
b_up   = [0, 0]
```

则：

```text
gate = [1, 2]
up   = [4, 7]
y    = [silu(1) * 4, silu(2) * 7]
     ~= [2.924, 12.337]
```

真实输出会按 `bf16` 存储，并按题目容差进行比较。
