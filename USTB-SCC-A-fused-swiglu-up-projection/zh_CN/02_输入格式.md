---
sectionTitle: "输入格式"
type: "Text"
---
本题没有传统标准输入。评测程序会在 GPU 上构造以下参数，并按顺序传入 `run_kernel`：

| 参数 | dtype | shape | 读写属性 | 说明 |
| --- | --- | --- | --- | --- |
| `x` | `bf16` | `(M, K)` | INPUT | 输入矩阵，连续 row-major 存储，不允许修改 |
| `w_gate` | `bf16` | `(K, N)` | INPUT | gate 分支权重矩阵，连续 row-major 存储，不允许修改 |
| `w_up` | `bf16` | `(K, N)` | INPUT | up 分支权重矩阵，连续 row-major 存储，不允许修改 |
| `b_gate` | `fp32` | `(N,)` | INPUT | gate 分支偏置，不允许修改 |
| `b_up` | `fp32` | `(N,)` | INPUT | up 分支偏置，不允许修改 |
| `y` | `bf16` | `(M, N)` | OUTPUT | 输出矩阵，初值未定义，必须完整写入 |
| `M` | `int64` | `()` | INPUT | `x` 与 `y` 的行数 |
| `K` | `int64` | `()` | INPUT | 规约维度 |
| `N` | `int64` | `()` | INPUT | 输出列数，也是偏置长度 |

所有 tensor 都是 contiguous。标量参数 `M`、`K`、`N` 为 Python `int`。
