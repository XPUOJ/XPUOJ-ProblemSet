---
sectionTitle: "输出格式"
type: "Text"
---
`run_kernel` 不需要向标准输出打印任何内容，也不需要返回值。参赛者需要完整写入输出 tensor `y`。

对每个 `0 <= i < M`、`0 <= j < N`，输出定义为：

```text
gate[i, j] = b_gate[j] + sum_{k=0}^{K-1} fp32(x[i, k]) * fp32(w_gate[k, j])
up[i, j]   = b_up[j]   + sum_{k=0}^{K-1} fp32(x[i, k]) * fp32(w_up[k, j])
y[i, j]    = bf16(silu(gate[i, j]) * up[i, j])
```

其中 `silu(t) = t / (1 + exp(-t))`。输出 tensor `y` 的初值未定义，不能依赖原有内容。
