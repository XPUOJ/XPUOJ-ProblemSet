给定 hidden states、专家权重、router logits 和 routing bias，实现 DeepSeek-style group-limited routing、两段专家 GEMM、SwiGLU 以及 top-k 加权聚合。不实现 EP/TP 通信，不要求量化路径。

令 `M` 为 token 数，`K` 为 hidden size，`N` 为单个专家 intermediate size，`E` 为输入权重包含的专家数。

1. `scores=sigmoid(router_logits)`；`choice_scores=scores+routing_bias[None,:]`。
2. 将专家分成 `n_groups` 组，每组的 group score 为组内最大两个 `choice_scores` 的和。
3. 选择 group score 最大的 `topk_groups` 个组，再在这些组中按 `choice_scores` 选择 `topk` 个专家。
4. 专家权重取自**未加 bias 的** `scores`，在选中的专家间归一化，再乘 `routed_scaling_factor`。Bias 只影响选择。
5. 每个 token、每个选中专家 `e` 计算：

```python
hidden = x[m].float() @ w1[e].float().T
gate, up = hidden.chunk(2, dim=-1)
activated = torch.nn.functional.silu(gate) * up
expert_out = activated @ w2[e].float().T
out_fp32[m] += topk_weights[m, t].float() * expert_out
```

最后将 FP32 聚合结果转换为 `x.dtype`，写入 `out`。

核心计算须使用 TileLang-MUSA，在 MTT S5000 上执行。允许少量 MUSA C++ 或 torch extension 辅助非核心计算。禁止调用 muBLAS、muDNN、MUTLASS 等现成算子库直接完成核心计算。
