---
sectionTitle: "输入格式"
type: "Text"
---
评测程序在 MUSA 设备上创建 Tensor，并按接口顺序调用 `run_kernel`。提交代码通过函数参数读取输入，无需读取标准输入。

| 参数 | shape | dtype / 类型 | 说明 |
| --- | --- | --- | --- |
| `x` | `[M,K]` | FP16 或 BF16 | 输入 hidden states |
| `w1` | `[E,2*N,K]` | 与 `x` 一致 | 专家的 gate/up 投影权重 |
| `w2` | `[E,K,N]` | 与 `x` 一致 | 专家的 down 投影权重 |
| `router_logits` | `[M,E]` | `torch.float32` | 路由分数的输入 |
| `routing_bias` | `[E]` | `torch.float32` | 仅影响专家选择的偏置 |
| `out` | `[M,K]` | 与 `x` 一致 | 输出缓冲区，由提交代码写入 |
| `topk` | 标量 | `int` | 每个 token 选择的专家数 |
| `n_groups` | 标量 | `int` | 专家分组数 |
| `topk_groups` | 标量 | `int` | 选择的专家组数 |
| `routed_scaling_factor` | 标量 | `float` | 归一化路由权重的缩放系数 |

所有 Tensor 连续、位于同一 MUSA 设备，输入元素均为有限值。除输出缓冲区 `out` 外，不得修改任何输入。

参数满足：

* `E % n_groups == 0`，每组包含至少 2 个专家。
* `1 <= topk_groups <= n_groups`。
* `1 <= topk <= topk_groups * (E // n_groups)`。

测试取 `n_groups=8`、`topk_groups=4`、`routed_scaling_factor=1.0`。
