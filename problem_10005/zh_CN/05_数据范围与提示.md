测试用例分为小尺寸正确性用例（1–6）与大尺寸性能用例（7–12）。全部用例均须通过正确性校验，性能指标按用例 7–12 聚合。`M` 为 token 数，`E` 为专家数，`K` 为 hidden size，`N` 为单个专家的 intermediate size。

测试覆盖两种输入精度、三种 `topk`、非 tile 整数倍维度、专家分组限制，以及会改变专家选择结果的 routing bias。

专家选择使用 `scores + routing_bias`；聚合权重使用未加 bias 的 `scores`。两者不得混用。每次调用均须覆盖 `out` 的全部元素。

正确性以 FP32 参考计算并转换到输出 dtype 后的结果为准。逐元素误差须满足：

```text
abs(actual - reference) <= atol + rtol * abs(reference)
```

* FP16：`rtol=1e-2`，`atol=2e-2`。
* BF16：`rtol=2e-2`，`atol=3e-2`。

不得输出 NaN 或 Inf。
