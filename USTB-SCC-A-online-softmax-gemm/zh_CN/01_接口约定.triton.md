你需要实现以下 Python 函数：

```python
def run_kernel(
    Q: torch.Tensor,      # [B, H, S, D]  bf16  只读
    K: torch.Tensor,      # [B, H, S, D]  bf16  只读
    V: torch.Tensor,      # [B, H, S, D]  bf16  只读
    mask: torch.Tensor,   # [B, 1, S, S] bf16  只读，可为 None（无 mask）
    B: int,               # batch size
    H: int,               # head 数
    S: int,               # 序列长度
    D: int,               # head 维度
    alpha: float,         # scale 因子
    O: torch.Tensor,      # [B, H, S, D]  bf16  输出，kernel 启动前内容未定义
) -> None:
```

**要求**：

1. 所有输入 tensor 均为 **bf16 连续存储**（row-major），位于 GPU 上
2. 必须使用 Triton 编写 GPU kernel
3. 禁止将中间结果 $S$ 或 $P$ 写出到全局内存再读回
4. 必须使用 online softmax 分块策略

**`mask` 语义**：

- 当 `mask is not None` 时，为 causal mask：上三角为 `-inf`，下三角（含对角线）为 `0`
- 当 `mask is None` 时，视为无 mask
- mask 形状为 `[B, 1, S, S]`
