你需要实现以下函数：

```cuda
extern "C" void run_kernel(
    const __nv_bfloat16* Q,     // [B, H, S, D]  只读
    const __nv_bfloat16* K,     // [B, H, S, D]  只读
    const __nv_bfloat16* V,     // [B, H, S, D]  只读
    const __nv_bfloat16* mask,  // [B, 1, S, S]  只读，可为 nullptr（无 mask）
    int64_t B,                  // batch size
    int64_t H,                  // head 数
    int64_t S,                  // 序列长度
    int64_t D,                  // head 维度（通常为 64 或 128）
    float   alpha,              // scale 因子，通常为 1 / sqrt(D)
    __nv_bfloat16* O            // [B, H, S, D]  输出，kernel 启动前内容未定义
);
```

**要求**：

1. `run_kernel` 内部自行计算 grid / block 维度并 launch kernel
2. 所有输入 tensor 均为 **bf16 连续存储**（row-major）
3. 所有输入 tensor 的值为随机初始化（范围 $[-1, 1]$），不会出现 NaN 或 Inf
4. 输出 `O` 必须**完整覆盖**，初值视为未定义，kernel 启动前不依赖其内容
5. 禁止修改四个只读输入 tensor（`Q`, `K`, `V`, `mask`）
6. 禁止将中间结果 $S$ 或 $P$ 完整写出到全局内存再读回

**`mask` 语义**：

- 当 `mask != nullptr` 时，其为 causal mask：上三角为 `-inf`（bf16 表示），下三角（含对角线）为 `0`
- 当 `mask == nullptr` 时，视为无 mask（等同于全 `0` mask）
- mask 形状为 `[B, 1, S, S]`，通过 broadcast 应用到所有 head

**提示**：

- 可以利用 `cp.async` 指令异步加载全局内存数据到共享内存
- 推荐使用 `__nv_bfloat162` 类型在寄存器中打包两个 bf16 值
- Tensor Core 操作使用 `mma.sync` 系列指令（SM 8.0）
- 注意 $S$ 维度可能不是 tile size 的整数倍，需处理边界
