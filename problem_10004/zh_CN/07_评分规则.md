正确性是成绩有效的前提。所有测试用例均须通过正确性校验；任一用例出现结果错误、超时、显存不足、运行失败或违反实现要求，该题提交不产生有效性能成绩。

### 计时方法

统一使用 MTT S5000 和赛事评测环境，以 MUSA events 测量算子调用耗时。每个计时用例先预热 20 次，再计时运行 50 次，记录中位数、最小值和最大值；排名仅使用中位耗时 `median_ms`。

Python 模块导入、首次 JIT 编译及扩展初始化在正式计时前完成。算子调用内部申请临时 MUSA buffer 的开销，按实际发生位置计入该次调用耗时。

### 单题性能指标

设参与性能聚合的第 `i` 个用例权重为 `weight_i`，中位耗时为 `median_ms_i`：

```text
weighted_geomean_ms = exp(
    sum_i(weight_i * log(max(median_ms_i, 1e-9))) / sum_i(weight_i)
)
```

`weighted_geomean_ms` 越低，单题排名越高。权重通过分母归一化。

本题各业务组的权重如下：

| 业务组 | 参数 | 权重 |
| --- | --- | --- |
| DSV4 paged | topk=512，page_size=64 | 45% |
| NSA paged | topk=2048，page_size=1 | 35% |
| NSA ragged | topk=2048 | 20% |

参与性能聚合的用例权重如下。用例 1–6 的性能权重为 0，但正确性校验仍必须通过。

| 用例 | 业务组 | 单用例权重 |
| --- | --- | --- |
| 7、8 | DSV4 paged | 各 22.5% |
| 9、10 | NSA paged | 各 17.5% |
| 11、12 | NSA ragged | 各 10% |

### 综合成绩

两道题均须取得有效成绩，才具备综合评奖资格。Indexer TopK Transform 占 40%，Fused MOE 占 60%；综合成绩计算方式及同分处理按赛事公告执行。

每道题多次提交取最优有效成绩。最终成绩以统一赛事环境复测结果为准。
