---
sectionTitle: "输入格式"
type: "Text"
---
评测程序在 MUSA 设备上创建 Tensor，并按接口顺序调用 `run_kernel`。提交代码通过函数参数读取输入，无需读取标准输入。

记 `B` 为行数，`S` 为每行的逻辑宽度，`P` 为页表宽度。

| 参数 | shape | dtype / 类型 | 说明 |
| --- | --- | --- | --- |
| `scores` | `[B,S]` | `torch.float32` | 分数矩阵，最后一维连续，行间可以存在额外步长 |
| `lengths` | `[B]` | `torch.int32` | 每行有效窗口长度 |
| `page_table` | `[B,P]` | `torch.int32` | PAGED 模式的物理页号 |
| `offsets` | `[B]` | `torch.int32` | RAGGED 模式的起始偏移 |
| `row_starts` | `[B]` | `torch.int32` | 有效窗口在 `scores` 中的起始位置 |
| `out` | `[B,topk]` | `torch.int32` | 连续的输出缓冲区，由提交代码写入 |
| `topk` | 标量 | `int` | 每行最多选择的索引数，大于 0 |
| `page_size` | 标量 | `int` | 页大小，大于 0 |
| `mode` | 标量 | `int` | `0` 为 PAGED，`1` 为 RAGGED |

所有 Tensor 位于同一 MUSA 设备。除 `scores` 外，各 Tensor 均连续。除输出缓冲区 `out` 外，不得修改任何输入。

每行满足 `0 <= lengths[b]`、`0 <= row_starts[b]` 和 `row_starts[b] + lengths[b] <= S`。

PAGED 模式下，`P >= ceil(max(lengths) / page_size)`；有效页号非负，同一行有效页号不重复，转换后的索引可以用 INT32 表示。RAGGED 模式下，`offsets[b]` 非负，转换后的索引可以用 INT32 表示。两种模式均须按函数签名传入全部参数，与当前模式无关的参数不参与计算。
