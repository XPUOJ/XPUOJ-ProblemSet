你必须在提交的 Python 代码中提供 `run_kernel` 函数，函数名、参数顺序、类型必须完全一致：

```python
def run_kernel(
    q,             # Tensor[float16], shape (B, seq_len, HQ, D)
    k,             # Tensor[float16], shape (B, seq_len, H, D)
    v,             # Tensor[float16], shape (B, seq_len, H, D)
    block_indices, # Tensor[int32], shape (B, seq_len, H, S)
    output,        # Tensor[float16], shape (B, seq_len, HQ, D)
    B,             # int64
    seq_len,       # int64
    H,             # int64
    HQ,            # int64
    D,             # int64
    S,             # int64
    block_size,    # int64
    is_causal,     # int64, 1 in tests
):
    ...
```

### 参数说明

* `q`：query tensor，shape `(B, seq_len, HQ, D)`
* `k`：key tensor，shape `(B, seq_len, H, D)`
* `v`：value tensor，shape `(B, seq_len, H, D)`
* `block_indices[b, t, h, s]`：第 `b` 个 batch、第 `t` 个 query、第 `h` 个 KV head 选中的第 `s` 个 KV block
* `output`：输出缓冲区，shape `(B, seq_len, HQ, D)`
* `block_size`：每个 sparse block 包含的 token 数
* `is_causal`：是否使用 causal mask，评测中固定为 1

无效 block 使用 `seq_len` 作为哨兵值。
