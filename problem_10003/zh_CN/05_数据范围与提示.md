测试点覆盖：

* `B`：1、2、4、8
* `seq_len`：64 到 8192
* `H`：1 或 2
* `HQ`：16 或 32
* `D`：32、64、128
* `S`：1、2、4、8
* `block_size`：16 或 32
* `is_causal`：1

注意：

* `G = HQ / H`，同一个 KV head 服务连续的 `G` 个 query heads。
* `block_indices` 中的无效 block 值为 `seq_len`，必须跳过。
* 输出参与 `torch.allclose` 校验，容差为 `rtol=1e-2, atol=1e-2`。
* 为保证计时准确，不建议在 `run_kernel` 内部调用显式同步。
