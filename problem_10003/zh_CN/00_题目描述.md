你需要实现 Native Sparse Attention 前向算子。

给定 query、key、value 以及每个 query token 选中的稀疏 block 下标，本题只对被选中的 KV block 做 causal attention：

```text
score = q @ k_selected^T / sqrt(D)
attention = softmax(score)
output = attention @ v_selected
```

其中 query heads 采用 GQA 布局：`HQ` 个 query heads 共享 `H` 个 KV heads，`G = HQ / H`。

评测程序会调用你提交代码中的 `run_kernel` 函数。你需要根据 `block_indices` 读取被选中的 KV block，并将结果写入 `output`。

如何提交代码详见[评测指南](/d/2)。
