你必须在提交的 Python 代码中提供 `run_kernel` 函数，函数名、参数顺序、类型必须完全一致：

```python
def run_kernel(
    q,        # Tensor[float16], shape (batch, heads, dim)
    q_pe,     # Tensor[float16], shape (batch, heads, pe_dim)
    kv,       # Tensor[float16], shape (batch, kv_ctx, kv_heads, dim)
    k_pe,     # Tensor[float16], shape (batch, kv_ctx, kv_heads, pe_dim)
    output,   # Tensor[float16], shape (batch, heads, dim)
    batch,    # int64
    heads,    # int64
    kv_heads, # int64
    kv_ctx,   # int64
    dim,      # int64, fixed to 512
    pe_dim,   # int64, fixed to 64
):
    ...
```

### 参数说明

* `q`：非 RoPE query，shape `(batch, heads, 512)`
* `q_pe`：RoPE query，shape `(batch, heads, 64)`
* `kv`：latent key/value cache，shape `(batch, kv_ctx, kv_heads, 512)`
* `k_pe`：RoPE key cache，shape `(batch, kv_ctx, kv_heads, 64)`
* `output`：输出缓冲区，shape `(batch, heads, 512)`

`run_kernel` 内部应自行计算 launch 配置，并调用 TileLang kernel 或等价 GPU tensor 算子完成计算。
