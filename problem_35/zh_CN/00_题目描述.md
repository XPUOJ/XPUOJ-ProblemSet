你需要实现 DeepSeek V3/R1 解码阶段使用的 Multi-Head Latent Attention 变体。

本题固定：

* query/key 的非 RoPE 维度 `dim = 512`
* RoPE 维度 `pe_dim = 64`
* QK 总维度为 `576`
* V/O 维度为 `512`
* `kv_heads = 1`，所有 query heads 共享同一组 latent KV

给定 `q`、`q_pe`、`kv`、`k_pe`，需要计算：

```text
score = (q @ kv^T + q_pe @ k_pe^T) / sqrt(576)
attention = softmax(score, dim=-1)
output = attention @ kv
```

评测程序会调用你提交代码中的 `run_kernel` 函数。你需要在函数内部完成 attention 计算，并将结果写入 `output`。

如何提交代码详见[评测指南](/d/2)。
